This workshop focuses on building particle system animations starting from an empty p5.js webpage. Rather than using pre-built libraries, the goal is to learn fundamental programming techniques and workflow practices applicable beyond just particle systems.

## Learning Objectives

-   Available tools and techniques in JavaScript and p5.js
-   Elements of productive programming workflows
-   Concepts applicable to broader coding projects outside this specific domain

## Workshop Structure

We start from an empty sketch and progress through a series of particle system animations, building skills incrementally through hands-on implementation.
