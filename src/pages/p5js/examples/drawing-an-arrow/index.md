p5 doesn't have an `arrow()` function, but you can. This function draws an arrow between two lines. It can be dashed.

I needed to [draw an arrow](https://www.openprocessing.org/sketch/1045212). I also needed to [adjust its end points](https://www.openprocessing.org/sketch/1045123), so that they did not overlap with the labels that the arrows joined.
