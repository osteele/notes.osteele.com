[sublimetext.com](https://www.sublimetext.com/)

A fast, lightweight text editor with a focus on speed and simplicity.

## Key Features

-   Extremely fast startup and file loading
-   Multiple cursors and selections
-   Command palette for quick access
-   Distraction-free writing mode
-   Split editing with multiple panes
-   Cross-platform (Windows, macOS, Linux)

## Package Control

Install Package Control to access thousands of plugins:

1.  Open Command Palette (Cmd/Ctrl + Shift + P)
2.  Search for "Install Package Control"
3.  Use "Package Control: Install Package" to add extensions

## Useful Packages

-   Emmet - HTML/CSS shortcuts
-   SideBarEnhancements - Better file management
-   A File Icon - File type icons
-   Theme - One Dark - Popular color theme
