# p5.js Templates

[p5.js Template (Glitch)](https://glitch.com/edit/#!/cclab-p5js-template?path=README.md%3A1%3A0) – Remix this to create a p5.js project on [Glitch](https://glitch.com). Adapted from a template by J.H. Moon

[p5.js Template (GitHub)](https://github.com/osteele/p5-template) – Download or clone this to create a p5.js project Visual Studio Code.

[p5pose](https://github.com/osteele/p5pose) is a p5.js + [ml5.js PoseNet](https://learn.ml5js.org/#/reference/posenet) starter. I prefer it to the official starter because I prefer for my students to use the [for…of statement](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/for...of). Also see [💃🏻PoseNet](/posenet/).
