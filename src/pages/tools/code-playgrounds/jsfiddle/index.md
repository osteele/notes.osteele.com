[jsfiddle.net](https://jsfiddle.net/)

A simple online editor for testing HTML, CSS, and JavaScript code snippets.

## Key Features

-   Four-panel layout (HTML, CSS, JS, Result)
-   Quick library inclusion (jQuery, React, etc.)
-   Easy sharing via URLs
-   Collaboration mode
-   Version history

## Using p5.js in JSFiddle

1.  In the JavaScript panel settings, add external resource
2.  Enter: `https://cdn.jsdelivr.net/npm/p5@1/lib/p5.min.js`
3.  Write your sketch code in the JavaScript panel
4.  Click "Run" to see results

## Best For

-   Quick code experiments
-   Sharing code for debugging help
-   Demonstrating bugs in libraries
