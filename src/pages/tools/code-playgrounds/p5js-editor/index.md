[editor.p5js.org](https://editor.p5js.org/)

The official online editor for p5.js, designed for beginners and quick experimentation.

## Key Features

-   Auto-refresh preview on code changes
-   File management for multi-file projects
-   Account system to save and share sketches
-   Sketch gallery and collections
-   Accessibility features built-in
-   Mobile-friendly interface

## Keyboard Shortcuts

-   `Cmd/Ctrl + Enter` - Run sketch
-   `Cmd/Ctrl + Shift + Enter` - Stop sketch
-   `Cmd/Ctrl + S` - Save
-   `Cmd/Ctrl + Shift + F` - Tidy code

## Adding Libraries

To add p5.js libraries or external JavaScript:

1.  Open Sketch > Add File
2.  Or edit index.html to add script tags

## Best For

-   Learning p5.js
-   Quick experiments
-   Sharing sketches for feedback
-   Teaching workshops
