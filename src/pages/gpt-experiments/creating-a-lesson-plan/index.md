Using ChatGPT to help develop educational content and lesson structures.

## The Task

I asked ChatGPT to help create a lesson plan for teaching p5.js to beginners. The prompt included:

-   Target audience (college students, no prior programming)
-   Time available (90 minute session)
-   Learning objectives
-   Available resources

## What Worked Well

-   Good structure with intro, activities, and wrap-up
-   Reasonable time estimates for activities
-   Suggested useful warm-up exercises
-   Included assessment ideas

## What Needed Adjustment

-   Some activities too ambitious for beginners
-   Needed more specific code examples
-   Follow-up prompts required to refine timing

## Best Practices

1.  Be specific about your audience's background
2.  Provide concrete time constraints
3.  Ask for multiple activity options
4.  Request modifications iteratively
