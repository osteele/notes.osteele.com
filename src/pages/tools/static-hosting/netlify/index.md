[netlify.com](https://www.netlify.com/)

A popular platform for deploying static sites and serverless functions.

## Deployment Options

### Drag and Drop

Drag a folder onto the Netlify dashboard to deploy instantly.

### Git Integration

1.  Connect your GitHub/GitLab/Bitbucket repo
2.  Configure build settings
3.  Automatic deploys on every push

### CLI

```bash
npm install -g netlify-cli
netlify deploy
```

## Features

-   Automatic HTTPS
-   Deploy previews for PRs
-   Serverless functions
-   Forms handling
-   Split testing (A/B)
-   Custom domains

## Free Tier

-   100GB bandwidth/month
-   300 build minutes/month
-   Unlimited sites
