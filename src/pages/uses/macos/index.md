# Productivity Software

***Mail***

[Mimestream](https://mimestream.com) native mail client.

***Calendar***

[Fantastical](https://flexibits.com/fantastical) – alternative to Apple Calendar. It has natural-language event entry, calendar sets, multiple-time event proposals, and conference call detection. It can hide events and ignore notifications from shared calendars.

***Task Management***

[Things](https://culturedcode.com/things/) – to do manager. I dump everything into this.

***Web browsers***

*Safari* as go-to browser. Main features: performance, battery life, tab-sharing with iPad and iPhone.

[Arc](https://arc.net/) for workspaces and ad hoc scrapbooks / dashboards (via Easels feature).

*Google Chrome* for when I need multiple personae. (Maybe I will switch to Arc now that it supports this.)

***Search Engines***: [Duck Duck Go](https://ddg.gg/), [Wikipedia](https://en.wikipedia.org/), [Wikiwand](https://www.wikiwand.com/en/).

***Communications***: Slack, Zoom, WeChat, Signal.

# Notes and Documents

[Apple Notes](https://support.apple.com/guide/notes/welcome/mac) for quick synchronized notes.

[Roam Research](https://roamresearch.com) for (initially) unstructured notes.

[Muse app](museapp.com/) nested spatial notes, syncs with iPad.

[Notion](https://www.notion.so/) for instructional material, drafts of other mixed-media documents, and web sites. [Super.so](https://super.so) for publishing Notion to the web.

[AirTable](https://airtable.com) for end-user databases (tables that include linked and calculated columns).

[Google Drive](https://www.google.com/drive/), Docs, and Sheets

[Apple Numbers](http://numbers.app). Killer feature: being able to include multiple tables and charts as separate entities on a single sheet, instead of mashing them all onto the same grid (or putting them on separate pages).

***Bookmarking***: Pinboard, Zotero. Previously: Delicio.us.

***Reading***: Apple Books, [Liquid Text](https://www.liquidtext.net), and Preview.

# Utilities

[1Password](https://1password.com) password manager.

[Bartender](https://www.macbartender.com) hides menu bar items.

[CleanMyMac](https://macpaw.com/cleanmymac)

[Daisy Disk](https://daisydiskapp.com) file size visualizer.

[Magnet](https://magnet.crowdcafe.com) tiling window manager.

[SetApp](https://setapp.com) is a software subscription service that provides many of the apps listed here, as well as others. It has the UI and UX that one wishes Apple's App Store did.

[Yoink](https://www.yoink.app) provides a temporary system-wide drop well for dragging between apps and screens. I'm not sure how one is supposed to use a Mac without this. (I've been using Macs since 1984.)

[TextSoap](https://textsoap.com/mac/) performs simple text transformations on the clipboard.

***Macros and Shortcuts***

*Apple Shortcuts*

[Raycast](https://www.raycast.com) Spotlight (and Alfred, and Quicksilver) replacement.

[Better Touch Tool](https://folivora.ai) can distinguish some keys that Raycast can’t. It is also the best tool for adding items and displays to the Touch Bar. (It does a lot more than this, but that’s all I use it for.) See [Shortcuts](/uses/shortcuts/).

[Keyboard Maestro](https://www.keyboardmaestro.com/main/). All my app launch shortcuts, plus a few more complicated macros to manage Sidecar and my VPN. See [Shortcuts](/uses/shortcuts/).

StreamDeck: out on loan.

***Utilities***: ForkLift, PDF Squeezer.

# Graphic Design

***Photo Editors***

[Pixelmator Pro](https://www.pixelmator.com/pro/) for quick and easy photo editing, retouching, and compositions.

[Affinity Photo](https://affinity.serif.com/en-us/photo/) (Adobe Photoshop alternative) for more involved photo projects. It is slower to launch; many things that can be done in either Pixelmator or Affinity can be done more easily in Pixelmator; but Affinity is more capable when Pixelmator hits the wall.

***Illustration***

[Affinity Designer](https://affinity.serif.com/en-us/designer/) (Adobe Illustrator alternative).

[OmniGraffle](https://www.omnigroup.com/omnigraffle) for diagrams. Magnets and movable arrows diagramming simpler and more flexible in OmniGraffle than any workflow I’ve yet found for Affinity Designer, Adobe Illustrator, or Sketch.

[~~Sketch](https://www.sketch.com) for vector graphics.~~ Most of my work is straight-up diagraming or illustration, not UI design, so I’ve mostly switched to Affinity Designer for what I used to use Sketch for.

***Design utilities***

[Sip](https://sipapp.io) application-independent screen color picker and formatter.

[PixelSnap](https://getpixelsnap.com) for taking screen measurements. (Previously: XScope.)

[Typeface](https://typefaceapp.com) is a font book. It organizes the fonts and includes sample text.

# Video Production

***Non-Linear Editors***

[Final Cut Pro](https://www.apple.com/final-cut-pro/) is my general-purpose go-to video editor. I prefer the Magnetic timeline, and of course its performance and crash-free experience, to Adobe Premier.

[DaVinci Resolve](https://www.blackmagicdesign.com/products/davinciresolve/). I am learning this; I may switch to it from Final Cut Pro.

[Screenflow](https://www.telestream.net/screenflow/overview.htm) for editing screencasts. It's simpler than Final Cut Pro / Resolve, and has built-in support for adding keyboard and mouse annotations in post-production (so that you don't have to burn them in at recording time).

***Transcoding and Playback***

[Permute](https://software.charliemonroe.net/permute/) for quickly transcoding media files.

*QuickTime Player* for video playback, and for quick video editing (trimming and extracting clips) when it's not worth creating a Final Cut project.

[Elmedia Player](https://www.elmedia-video-player.com) is an alternative to QuickTime Player, with better support for playhead positioning and subtitles.

[Downie](https://software.charliemonroe.net/downie/) for downloading videos from web sites – generally to use as B roll or as backup during presentations.

***Motion graphics and effects***: Apple Motion; Blender. I am learning DaVinci Fusion, and may switch to this.

[Presentify](https://presentify.compzets.com) – adds a menu bar (confusingly, called Annotate instead of Presentify) that lets you mark up the screen. This is similar to Zoom’s whiteboard mode.

*OBS* for compositing multiple video sources more flexibly (although with lower-quality virtual greenscreening) than Zoom is capable of. Plug-ins: Background Remover, Effects, Move.

# Screenshot Capture and Recording

I use a ~~ridiculous~~ number of screenshot apps (*I’ve winnowed this down as Cleanshot becomes more capable*), but they each have different strengths. These are useful for preparing instructional material and other documentation; also, the occasional bug report.

![](/images/macos/macos-02.png)

## [Cleanshot](https://cleanshot.com)

- Screenshot or movie of a window or area.
- Supports scrolling capture
- Timer
- Optionally hides desktop icons, replaces by solid color or wallpaper.
- Supports annotation, but the UI is heavier-weight than Xnip.
- Has a cloud feature that I don't use.
- Its strengths for me are recordings: include audio and webcam, show mouse and keystroke, hide notifictions, save as movie or gif.
- Includes a “pin to screen” feature. TODO: Evaluate this compared to the same feature of ScreenFloat.

## [ScreenFloat](https://screenfloatapp.com/)

- Leaves shots pinned to the the screen. This is useful for making a snapshot of one window or tab to use as a static reference while working in another window or tab. I also use it for working with multiple “sheet tabs” of a Google Sheet, as a lightweight alternative to placing two windows side by side.
- Screenshots are shown with a file proxy icon that can be dragged anywhere that expects a file, including the File Open dialog or a the upload drop zone of a web page. This is the screenshot utility that makes it easiest to move a screenshot into a web app or desktop application that doesn't accept pasted graphics.
- Includes a shots browser that I don't use.
- From the author of [Yoink](http://eternalstorms.at/yoink).
