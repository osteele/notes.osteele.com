Web-based editors for writing and running p5.js sketches.

## Recommended

### p5.js Web Editor

[editor.p5js.org](https://editor.p5js.org/)

The official p5.js editor. Best for beginners and quick experiments.

-   Auto-refresh on code changes
-   File management for multi-file projects
-   Account system to save sketches
-   Gallery to share and discover sketches

### OpenProcessing

[openprocessing.org](https://openprocessing.org/)

A community platform with a large library of shared sketches.

-   Extensive sketch gallery for inspiration
-   Classroom features for teaching
-   Fork and remix others' sketches

## General-Purpose Editors

### Glitch

[glitch.com](https://glitch.com/)

Full-featured web development environment. Great for projects that need server-side code.

### CodePen

[codepen.io](https://codepen.io/)

Popular for sharing code snippets. Good for embedding sketches in other sites.

### CodeSandbox

[codesandbox.io](https://codesandbox.io/)

More powerful editor with VS Code-like features.
