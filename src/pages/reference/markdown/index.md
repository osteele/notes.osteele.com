## Markdown Editors

### Typora

[Typora](https://typora.io/) is described as "a new way to read & write Markdown." It removes preview windows and syntax symbols for cleaner writing, providing real-time live preview to help users focus on content.

### Visual Studio Code

[Visual Studio Code](https://code.visualstudio.com/) offers built-in Markdown editing functionality with basic editing features plus Markdown-specific tools. It supports extensions for enhanced capabilities.
