**Note:** Atom was sunset by GitHub in December 2022. Consider using VS Code or other alternatives.

## Overview

Atom was a free, open-source text editor developed by GitHub. It was known for being "hackable to the core" with extensive customization options.

## Key Features (Historical)

-   Built on Electron (web technologies)
-   Extensive package ecosystem
-   Git integration
-   Teletype for real-time collaboration
-   Customizable themes and syntax highlighting

## Alternatives

-   [Visual Studio Code](/tools/code-editors/visual-studio-code/) - Similar architecture, actively maintained
-   [Sublime Text](/tools/code-editors/sublime-text/) - Fast and lightweight
-   Pulsar - Community fork of Atom
