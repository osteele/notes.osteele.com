[vercel.com](https://vercel.com/)

Platform for frontend frameworks and static sites, created by the makers of Next.js.

## Deployment

### Git Integration

1.  Import your repository
2.  Vercel auto-detects the framework
3.  Deploys automatically on push

### CLI

```bash
npm install -g vercel
vercel
```

## Features

-   Automatic HTTPS
-   Preview deployments
-   Edge functions
-   Analytics
-   Instant rollbacks
-   Optimized for Next.js, but works with any framework

## Framework Support

Zero-configuration for:

-   Next.js, Nuxt, SvelteKit
-   React, Vue, Angular
-   Astro, Gatsby, Hugo
-   Plain HTML/CSS/JS

## Free Tier (Hobby)

-   100GB bandwidth/month
-   Unlimited websites
-   Serverless functions included
