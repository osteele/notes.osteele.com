[codepen.io](https://codepen.io/)

A social development environment for front-end designers and developers.

## Key Features

-   Live preview as you type
-   HTML, CSS, and JavaScript panels
-   Easy embedding in other sites
-   Large community and collections
-   Preprocessor support (Sass, Less, etc.)

## Using p5.js in CodePen

1.  Create a new Pen
2.  Click Settings > JS
3.  Add external script: `https://cdn.jsdelivr.net/npm/p5@1/lib/p5.min.js`
4.  Write your p5.js code in the JS panel

## Pros and Cons

### Pros

-   Great for sharing code snippets
-   Easy to embed in blog posts
-   Active community for inspiration

### Cons

-   Free tier limited to single-file projects
-   No file management on free tier
