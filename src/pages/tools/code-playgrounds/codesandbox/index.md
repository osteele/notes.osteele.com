[codesandbox.io](https://codesandbox.io/)

A powerful online IDE for web development with full VS Code features.

## Key Features

-   VS Code-like editing experience
-   Multi-file project support
-   npm package installation
-   Git integration
-   Live collaboration
-   Deployment to various platforms

## Templates

Start quickly with pre-configured templates:

-   React, Vue, Angular
-   Vanilla JavaScript
-   Node.js server
-   Static HTML/CSS/JS

## For p5.js

1.  Create a new sandbox from "Static" template
2.  Add p5.js via npm or CDN in index.html
3.  Create your sketch files
