Alternatives generate a QR code for a URL:

- In Chrome, click the Share icon, and select Create QR Code. This creates a Frame QR with a dinosaur icon in the canvas area.
- In Raycast, install [QR Code Generator](https://www.raycast.com/Melvynx/qrcode-generator).  Running this extension opens a Model 2 (frameless) QR code in Preview.
- iOS: Install [this Shortcut](https://chrome.google.com/webstore/search/qr%20code). It adds an item “Generate QR Code” to the share sheet. Share this from Safari (or another app that publishes a URL), to both preview the code and place it in the clipboard. (You can also add it in the macOS Shortcuts menu bar icon. When invoked from the menu bar, it encodes the contents of the current clipboard; it doesn’t read the current browser page URL.)
