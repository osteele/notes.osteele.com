[openprocessing.org](https://openprocessing.org/)

A creative coding community focused on p5.js and Processing.js sketches.

## Key Features

-   Built specifically for creative coding
-   Large gallery of community sketches
-   Fork and remix others' work
-   Classroom management tools
-   Curated collections and challenges

## For Teachers

OpenProcessing offers classroom features:

-   Create classes with private or public access
-   Assign homework and projects
-   Review and comment on student work
-   Share code templates for assignments

## Discovering Work

-   Browse by tags and collections
-   Follow other creators
-   Participate in weekly challenges
