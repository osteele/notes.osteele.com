Comparing how GPT-4V describes images using different prompting styles.

## The Experiment

Given the same image, I asked for descriptions in various styles:

-   Technical/objective
-   Poetic/evocative
-   Accessibility-focused (for screen readers)
-   Art critic style
-   Child-friendly

## Observations

### Technical Style

Precise, listing objects, colors, and spatial relationships.

### Poetic Style

More metaphorical, focused on mood and feeling.

### Accessibility Style

Concise but complete, prioritizing key information for navigation.

## Applications

-   Generating alt text for images
-   Creating image captions
-   Describing art for catalogs
-   Making visual content accessible
