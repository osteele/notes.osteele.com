[glitch.com](https://glitch.com/)

A friendly platform for building full-stack web apps with instant hosting.

## Key Features

-   Full Node.js server support
-   Instant live URLs for projects
-   Remix (fork) other projects easily
-   Real-time collaboration
-   Free SSL certificates
-   Persistent storage

## Project Types

-   **Static site** - HTML, CSS, JS only
-   **Node.js** - Full server with Express, etc.
-   **SQLite** - Database-backed projects

## For p5.js

Glitch works well for p5.js projects that need:

-   Server-side components
-   Persistent data storage
-   WebSocket communication
-   Custom API endpoints

## Limitations

-   Projects sleep after 5 minutes of inactivity (free tier)
-   Limited disk space
-   No custom domains on free tier
