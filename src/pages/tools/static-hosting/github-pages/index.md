[pages.github.com](https://pages.github.com/)

Free static site hosting directly from a GitHub repository.

## Setup

### For a Project

1.  Go to repository Settings > Pages
2.  Select source branch (usually main or gh-pages)
3.  Choose folder (root or /docs)
4.  Site will be at `username.github.io/repo-name`

### For a User/Organization Site

1.  Create a repo named `username.github.io`
2.  Add your HTML files
3.  Site will be at `username.github.io`

## Features

-   Free hosting with HTTPS
-   Custom domain support
-   Jekyll integration for blogs
-   GitHub Actions for builds

## Limitations

-   Static files only (no server-side code)
-   1GB repository size limit
-   100GB/month bandwidth
-   10 builds per hour limit
