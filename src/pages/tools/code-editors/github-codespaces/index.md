[github.com/features/codespaces](https://github.com/features/codespaces)

Cloud-hosted development environments powered by VS Code.

## Key Features

-   Full VS Code experience in the browser
-   Pre-configured development containers
-   Connect from local VS Code or browser
-   GPU-enabled machines available
-   Persistent storage and settings sync

## Use Cases

-   Working from any computer without local setup
-   Onboarding new team members quickly
-   Testing in consistent environments
-   Projects requiring specific dependencies

## Pricing

Free tier includes 60 hours/month on 2-core machines. Additional usage is billed hourly.
