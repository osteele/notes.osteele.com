Design and build a stand to display or hold a small object.

## Objectives

-   Practice joinery techniques
-   Design for a specific use case
-   Work with angles and/or curves

## Examples

-   Phone/tablet stand
-   Plant holder
-   Book stand
-   Jewelry display
-   Kitchen utensil holder

## Requirements

-   Must use at least one joinery technique (dado, rabbet, or mortise)
-   Must be stable when holding intended object
-   Finished with appropriate treatment for use

## Process

1.  Identify the object you're designing for
2.  Sketch multiple design options
3.  Create a prototype or mockup
4.  Build final version
5.  Document your process
