[replit.com](https://replit.com/)

A collaborative browser-based IDE supporting many programming languages.

## Key Features

-   50+ programming languages supported
-   Multiplayer real-time collaboration
-   Built-in hosting with custom URLs
-   AI coding assistant (Ghostwriter)
-   Mobile app available
-   Package management built-in

## Languages

Popular options include:

-   Python, JavaScript, TypeScript
-   Java, C++, C#
-   Ruby, Go, Rust
-   HTML/CSS/JS for web

## For p5.js

1.  Create a new "HTML, CSS, JS" repl
2.  Add p5.js CDN link in index.html
3.  Write your sketch in script.js
