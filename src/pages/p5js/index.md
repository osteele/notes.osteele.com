## Creating and Editing Sketches

You can work with p5.js using either online editors (no setup required) or local applications (for users comfortable with code environments).

### Online Playgrounds

Browser-based editors where you don't have to create an HTML file, so you can focus on the code in your sketch:

<ul class="page-list"><li><a href="https://editor.p5js.org/">P5 Web Editor</a> – Official p5.js editor</li><li><a href="https://openprocessing.org/">OpenProcessing.org</a> – Community tutorials and curated collections</li><li><a href="https://glitch.com/">Glitch</a> – Online coding platform</li></ul>

### Local Development

[Visual Studio Code](https://code.visualstudio.com/) is recommended for local development. See the setup guide for configuration instructions.
