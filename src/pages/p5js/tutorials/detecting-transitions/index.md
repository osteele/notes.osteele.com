Learn how to tell when the mouse _enters_ a rectangle, instead of when it is inside of it at the moment.

## Key Concept

The core difference being taught is between:

-   **Continuous state detection:** Checking if the mouse is currently within an area
-   **Transition detection:** Recognizing the specific moment when the mouse crosses into (or out of) a boundary

## Why This Matters

This technique is valuable for interactive programming because it allows developers to trigger actions at precise moments rather than repeatedly throughout a duration. In p5.js contexts, this enables more efficient event handling and responsive interactions.
