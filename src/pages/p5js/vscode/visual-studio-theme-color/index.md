For some reason, programmers really like white-on-black text.

![](/images/visual-studio-theme-color/image.png)

If you prefer white-on-black text…

![](/images/visual-studio-theme-color/image_720.png)

… then select a different color theme via the *Code > Preferences > Color Theme* menu item:

![](/images/visual-studio-theme-color/image_720 1.png)

I use a light theme such as “Light (Visual Studio)”. 

## Colored Tabs

The ["indent-rainbow” extension](https://marketplace.visualstudio.com/items?itemName=oderwat.indent-rainbow) gives  colored tabs. These make it easier to read `if`s inside `function`, and `if`s inside `if`s, and so forth.

![](/images/visual-studio-theme-color/image 1.png)
